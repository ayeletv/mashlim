בדיקת חיבור ל-Firebase

לוחצים על הכפתור — העמוד ינסה לכתוב ולקרוא רשומת בדיקה מה-Firestore של פרויקט minyan-540d0. אם זה עובד, סימן שהחיבור תקין ואפשר להתקדם.

אם קיבלת שגיאת "permission-denied": זה תקין — Firestore חוסם גישה כברירת מחדל. יש להיכנס ל-Firebase Console → Firestore Database → לשונית Rules, ולהדביק זמנית: 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /connection_test/{doc} {
      allow read, write: if true;
    }
  }
}
ואז ללחוץ Publish ולנסות שוב. (זו הרשאה זמנית לבדיקה בלבד — לפני שהאתר עולה לאוויר באמת נגדיר הרשאות מאובטחות כמו שצריך.)
